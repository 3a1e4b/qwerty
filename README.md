# Репозиторий

Небольшой репозиторий, содержащий SSH-публичный ключ.

## Структура

- `id_rsa.pub` — публичный SSH-ключ (RSA).
- `README.md` — этот файл.

## Использование

Публичный ключ можно добавить в `~/.ssh/authorized_keys` на удалённом сервере
для настройки входа по SSH без пароля:

```bash
cat id_rsa.pub | ssh user@host "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

## Безопасность

В репозитории хранится только публичная часть ключа — это безопасно.
Никогда не добавляйте приватный ключ (`id_rsa`) в репозиторий.
